예시 데이터

고용노동부·안전보건공단 안전보건 이슈, 중대재해 관련 뉴스를 카테고리·키워드·날짜로 검색합니다. 최근 뉴스만 훑어보려면 대시보드 상단의 자동 스크롤 게시판을 이용하고, 예전 기사를 찾거나 특정 기간의 사고 소식을 모아보려면 여기서 검색하세요. 뉴스는 발행일 기준 설정 > 안전보건 뉴스 게시판의 "보관 기간"(기본 6개월)이 지나면 자동 삭제되므로 그보다 오래된 기사는 나오지 않습니다 — 계속 남겨두고 싶은 기사는 목록에서 "보관"을 눌러두면 기간이 지나도 삭제되지 않습니다.

KOSHA 가이드 등록

여러 건 한 번에 붙여넣기 (일괄 등록)

한 줄에 하나씩, 지침번호, 분야, 제목, 제개정일자(YYYYMMDD), 링크 순서로 쉼표(,)나 탭으로 구분해서 붙여넣으세요. 지침번호가 이미 등록되어 있으면 그 항목을 덮어쓰고, 없으면 새로 추가합니다 (같은 목록을 다시 붙여넣어도 중복 등록되지 않습니다). 지침번호를 모르면 맨 앞을 비워두고 쉼표만 남겨도 됩니다.
예) G-68-2022,안전분야,밀폐공간 작업 안전보건에 관한 기술지침,20220401,https://example.com/guide.pdf

본문 검색

지침번호·제목뿐 아니라, 본문(PDF 원문 텍스트)까지 대상으로 검색해 미리보기를 보여줍니다. 다만 동기화나 일괄 등록은 원문 링크만 주고 본문 텍스트 자체는 주지 않으므로, 검색에서 실제 내용까지 찾으려면 먼저 "본문 캐시 채우기"를 눌러 원문 링크가 있는 가이드들의 PDF에서 텍스트를 미리 뽑아둬야 합니다 (PDF를 직접 첨부한 가이드는 첨부하는 순간 자동으로 채워집니다). 한 번 누르면 남은 건수가 0이 될 때까지 (또는 더 이상 진행이 안 될 때까지) 자동으로 이어서 처리합니다. 이미 캐시해뒀고 그 뒤로 원문 링크가 바뀌지 않은 항목은 건너뛰므로, 나중에 다시 눌러도 새로 개정되어 링크가 바뀐 항목만 처리합니다.

등록된 KOSHA 가이드

제목을 누르면 동기화/등록 시 받아온 원문 링크로 바로 이동합니다. 원문 링크가 없는 항목은 제목이 클릭되지 않습니다 - "수정"에서 원문 링크를 직접 채워두거나, API 동기화가 링크를 못 채워온 경우라면 "수정"에서 PDF 파일을 직접 첨부해도 그때부터 클릭할 수 있습니다.

사용 설명서

이 시스템은 별도의 기술지원 없이 사내에서 자체적으로 운영됩니다. 궁금한 점이 생기면 이 설명서를 먼저 확인해주세요 — 화면 곳곳의 회색 안내 문구(설정 탭 각 항목 아래)에도 같은 내용이 더 자세히 적혀 있습니다.

처음 시작하기 보안/개인정보 대시보드 안전보건 뉴스 법령 마스터 개정 이력 KOSHA 가이드 키워드 검색 사규 / 사규 개정 이력 설정 자주 묻는 질문

1. 처음 시작하기 (순서대로)

  1. 설정 > 국가법령정보센터 Open API에서 OC 키를 입력합니다. OC 키가 없으면 실제 법령 데이터 대신 예시(데모) 데이터로만 화면이 채워집니다. 발급 방법: open.law.go.kr에서 회원가입 후 "오픈API" 신청 (승인되면 신청 시 쓴 아이디 앞부분이 OC 값입니다).
  2. 법령 마스터 탭에서 관리할 법령·고시를 검색해서 추가합니다. 플랜트건설업 관련 기본 법령을 한 번에 넣고 싶다면 설정 > 플랜트건설업 기본 법령 세트의 "기본 법령 세트 추가" 버튼을 눌러도 됩니다.
  3. 우측 상단의 새로고침 버튼을 한 번 눌러 최초 동기화를 실행합니다. (매일 자동으로도 실행되니 평소에는 굳이 안 눌러도 됩니다.)
  4. 설정 > 신규 제정 고시 자동 탐지에서 소관부처/키워드가 우리 회사와 맞는지 확인하고, 기준일을 오늘 날짜로 넣어두면 이 프로그램을 설치하기 전의 오래된 고시가 "신규 후보"로 잔뜩 나오는 걸 막을 수 있습니다.
  5. 키워드 검색을 쓰려면 본문이 미리 캐시되어 있어야 합니다. 설정 > 법령 본문 캐시(또는 더 넓은 범위가 필요하면 전체 법령 자동 캐시)에서 한 번 새로고침해두세요.

보안/개인정보

이 프로그램은 사용자의 PC(또는 사내 서버)에서 직접 실행됩니다. 등록한 법령·고시 정보와 사규(회사 문서) 정보는 로컬 데이터베이스 파일에만 저장되며, 국가법령정보센터(법령 조회) 외에는 어떤 외부 서버로도 전송되지 않습니다.

대시보드

  • 안전보건 이슈 · 중대재해 뉴스: 고용노동부·안전보건공단 안전보건 이슈와 중대재해 뉴스를 자동 스크롤 게시판으로 보여줍니다. 항목을 클릭하면 원문으로 이동하고, 상단 필터로 기관별로 좁혀볼 수 있습니다. 출처(RSS 주소)는 설정 탭에서 바꿀 수 있습니다.
  • 키워드 검색창: 법령명뿐 아니라 본문(조문 내용)까지 검색합니다 (본문 캐시가 되어 있어야 결과가 나옵니다).
  • 법령 개정 리스트: 등록해둔 법령·고시가 실제로 재·개정된 것이 감지되면 여기 모두 표시됩니다 (이 시스템의 핵심 기능).
  • 신규 제정 고시 후보: 아직 등록하지 않은 고시·예규·훈령 중, 설정에서 지정한 소관부처+키워드(+기준일)에 맞는 것을 찾아 보여줍니다. "등록"을 누르면 정식으로 관리 목록에 추가되고, "무시"를 누르면 다시 뜨지 않습니다.
  • 사내 절차서·지침서 개정 필요 사항: 근거 법령이 개정된 사규만 문서 기준으로 모아서 보여줍니다 (사규 탭에서 근거 법령을 매핑하거나 키워드(해시태그)를 등록해둬야 나타납니다).
  • 목록이 길어지면 표 안에서만 스크롤됩니다 — 계속 등록/무시를 눌러도 페이지 전체가 늘어지지 않습니다.
  • 우측 상단의 종 모양 알림(🔔)은 아직 검토하지 않은 개정 건수를 보여주며, 클릭하면 확인 처리됩니다.

안전보건 뉴스

대시보드 게시판(자동 스크롤)과 같은 데이터를 대상으로, 별도 화면에서 카테고리·키워드(제목)·날짜 범위로 검색합니다. "전체보기 · 검색" 버튼(대시보드 게시판 우측)이나 상단 탭에서 들어갈 수 있습니다. 뉴스는 발행일 기준 설정 > 안전보건 뉴스 게시판의 "보관 기간"(기본 180일 = 6개월)이 지나면 자동 삭제됩니다 — 계속 남겨두고 싶은 기사는 목록에서 "보관"을 눌러두면 기간이 지나도 삭제되지 않고, "보관함만 보기"로 모아볼 수 있습니다. 더 넓은 기간을 검색하려면 설정에서 보관 기간 값을 늘려두세요. 조건에 맞는 뉴스가 하나도 없으면(보관 기간이 지나 정리됐거나, 애초에 이 화면이 다루는 3개 피드에 뜬 적 없는 기사인 경우) "외부 브라우저에서 검색하기" 버튼으로 같은 검색어를 구글 뉴스에서 바로 찾아볼 수 있습니다.

법령 마스터

법령명으로 검색해서 추적할 법령·고시를 추가/삭제하는 화면입니다. 여기에 등록된 항목만 "법령 개정 리스트"에서 자동으로 추적됩니다. 법령/시행령/시행규칙과 고시·예규·훈령(행정규칙)을 구분해서 검색할 수 있습니다.

개정 이력

감지된 모든 개정 건의 이력입니다. 상태(미검토/검토중/반영완료/해당없음)로 필터링하거나, 여러 건을 한 번에 선택해서 상태를 일괄 변경할 수 있습니다. 검토 담당자가 실제로 사규에 반영했는지 확인하며 상태를 바꿔나가는 용도입니다.

KOSHA 가이드

한국산업안전보건공단(KOSHA)이 발간하는 기술지침(KOSHA GUIDE)을 등록해서 관리하는 화면입니다. 세 가지 방법으로 채울 수 있습니다:

  • API로 동기화: 공공데이터포털에서 "한국산업안전보건공단_안전보건법령 스마트검색" API 활용신청이 승인되면, 설정 > "KOSHA 가이드 Open API"에 인증키를 저장한 뒤 이 버튼을 누르면 설정에 등록해둔 키워드로 자동 검색해서 채웁니다.
  • 가이드 추가: 한 건씩 직접 입력합니다.
  • 여러 건 한 번에 붙여넣기(일괄 등록): "KOSHA 가이드 등록" 패널을 펼치면 갖고 있는 목록을 붙여넣어 한 번에 여러 건을 등록할 수 있습니다.

등록된 KOSHA 가이드 목록(또는 검색 결과)에서 제목을 누르면 저장된 원문 링크로 바로 이동합니다. API 동기화로 받아온 항목은 공공데이터포털 응답에 원문 링크가 없는 경우 제목이 클릭되지 않을 수 있는데, 그럴 땐 "수정"에서 원문 링크를 직접 채워두세요.

지침번호·제목뿐 아니라 본문(입력한 경우)까지 검색하려면 아래 본문 검색 패널을 사용하세요.

키워드 검색

등록해두었거나 본문 캐시로 미리 받아둔 법령·고시를 대상으로 키워드/문장을 검색합니다. 법령명뿐 아니라 조문 본문까지 검색되므로 "화기작업"처럼 이름에는 없어도 본문에 포함된 내용까지 찾아줍니다. 결과가 안 나온다면 캐시가 비어 있는 경우가 대부분이니, 설정 > 법령 본문 캐시(또는 전체 법령 자동 캐시)를 먼저 실행해주세요. 검색 결과의 본문 발췌문을 클릭하면 국가법령정보센터의 해당 조문으로 바로 이동합니다 (조번호를 알 수 없는 별표/부칙 등은 법령 전체 페이지로 이동합니다).

사규 / 사규 개정 이력

사규 탭에서 절차서·지침서 등 회사 문서를 등록하고, 그 문서의 근거가 되는 법령·고시를 직접 선택(매핑)하거나 키워드(해시태그)를 등록해둘 수 있습니다. 키워드를 등록해두면 근거 법령을 일일이 고르지 않아도, 그 키워드가 이름/본문에 포함된 법령·고시가 개정될 때 자동으로 이 문서가 "개정 필요 사항"에 뜹니다. 사규 개정 이력 탭은 이렇게 문서 기준으로 재구성한 개정 이력을 모아 보여줍니다.

설정

  • 플랜트건설업 기본 법령 세트: 플랜트건설업 관련 안전보건 법령을 한 번에 검색해서 추가합니다. 이미 등록된 항목은 건너뛰므로 여러 번 눌러도 안전합니다.
  • 신규 제정 고시 자동 탐지: 소관부처 + 키워드(이중 필터) + 기준일로 신규 후보를 찾는 조건을 설정합니다. "새로고침"을 누를 때와 매일 새벽 1시에 자동 실행됩니다.
  • 무시한 신규 고시 후보 관리: "무시"를 누른 고시는 계속 숨겨지고 다시 안 뜹니다. 잘못 무시했거나 다시 필요해지면 여기서 찾아서 "복원"할 수 있습니다.
  • 법령 본문 캐시: 키워드 검색과 사규 키워드 자동 매칭에 쓰이는 본문 데이터를 새로고침합니다 ("신규 제정 고시" 설정의 부처/키워드 범위를 따릅니다).
  • 안전보건 뉴스 게시판: 대시보드 게시판에 표시할 고용노동부·안전보건공단·중대재해 뉴스의 RSS/Atom 피드 주소와 표시 여부를 설정합니다. 기본 주소로도 바로 동작하며, "지금 새로고침"으로 즉시 가져올 수 있습니다.
  • 전체 법령 자동 캐시: 부처/키워드에 상관없이 법령·행정규칙 전체를 대상으로 본문을 캐시합니다. 처음 한 번은 대상이 많아 몇 시간 이상 걸릴 수 있지만, 이후로는 바뀐 것만 다시 받아와 빨라집니다. 매일 새벽 1시 자동 실행 여부를 켜고 끌 수 있습니다.
  • 국가법령정보센터 Open API: OC 키를 입력/변경합니다. 비워두면 데모 데이터로 동작합니다.
  • KOSHA 가이드 Open API: 공공데이터포털 "안전보건법령 스마트검색" API 인증키/요청 URL/동기화 키워드를 설정합니다. KOSHA 가이드 탭의 "API로 동기화" 버튼이 이 설정을 사용합니다.
  • 자동 동기화: 서버가 실행되어 있는 동안 자동으로 몇 시간마다 동기화할지 보여줍니다 (.env 설정, 관리자 영역).

자주 묻는 질문

  • 데이터가 하나도 안 보여요. 설정에서 OC 키가 입력되어 있는지, 법령 마스터에 법령이 하나 이상 등록되어 있는지 확인하세요.
  • 새로고침을 눌러도 개정이 안 잡혀요. 실제로 아직 개정되지 않은 것일 수 있습니다. 매일 새벽 1시에도 자동으로 확인하니 평소에는 그대로 두어도 됩니다.
  • 키워드 검색 결과가 없어요. 본문 캐시가 비어 있을 가능성이 큽니다. 설정 > 법령 본문 캐시(또는 전체 법령 자동 캐시)에서 새로고침하세요.
  • 전체 법령 자동 캐시가 너무 오래 걸려요. 대상이 수만 건이라 처음 한 번만 그렇습니다. 공포번호가 바뀐 것만 다시 받아오므로, 두 번째 실행부터는 훨씬 빨라집니다.
  • 프로그램(run.bat)을 껐다 켜면 데이터가 사라지나요? 아니요. 모든 데이터는 이 PC에 파일로 저장되어 그대로 유지됩니다.
  • 신규 제정 고시 후보에 예전 고시가 너무 많이 나와요. 설정 > 신규 제정 고시 자동 탐지에서 기준일을 오늘 날짜(또는 원하는 날짜)로 설정하세요. 그 이후 공포된 것만 후보로 표시됩니다.
  • 분명히 조건에 맞는 고시인데 후보에 안 떠요. 예전에 "무시"를 눌렀던 항목일 수 있습니다. 설정 > 무시한 신규 고시 후보 관리에서 확인하고 "복원"해보세요.

플랜트건설업 기본 법령 세트

플랜트건설업에 저촉되는 안전보건 관련 법령·고시를 한 번에 검색해서 관리 목록에 추가합니다. 이미 관리 중인 항목은 건너뜁니다 — 다시 눌러도 안전합니다.

신규 제정 고시 자동 탐지

고시는 기존 것이 "개정"되는 게 아니라 매년 새로 "제정"되는 경우가 많아, 등록해둔 항목만 추적해서는 놓칠 수 있습니다. 소관부처가 아래 부처와 일치하면서, 이름에 키워드 중 하나라도 포함된 아직 등록 안 한 고시·예규·훈령을 찾아 대시보드에 후보로 보여줍니다 (부처 AND 키워드, 이중 필터). "새로고침"을 누를 때마다, 그리고 매일 새벽 1시에도 자동으로 실행됩니다. 기준일을 설정하면 그 날짜 이후에 공포된 것만 후보로 보여줍니다 (다른 PC에 설치할 때, 과거 고시가 전부 "신규"로 쏟아지는 걸 막는 용도). 비워두면 전체 기간이 대상입니다.

무시한 신규 고시 후보

"신규 제정 고시 후보"에서 "무시"를 누른 항목은 조건에 다시 맞아도 재등장하지 않습니다. 잘못 눌렀거나 다시 필요해진 항목은 여기서 확인하고 복원하면 다음 새로고침 때부터 다시 후보 목록에 나타납니다.

법령 본문 캐시

국가법령정보센터 API는 법령명 검색만 지원하고 전체 법령 대상 본문검색은 제공하지 않습니다. 그래서 본문검색과 사규 키워드(해시태그) 자동 매칭은 여기서 미리 받아둔 본문 캐시를 대상으로 동작합니다. 추적 중인 법령·고시의 본문은 동기화할 때마다 자동으로 갱신되고, 아직 등록하지 않은 법령까지 포함한 더 넓은 범위는 아래 버튼으로 직접 새로고침해야 합니다(위 "신규 제정 고시" 키워드/부처 설정을 그대로 사용합니다).

전체 법령 자동 캐시

위 "본문 캐시 새로고침"은 "신규 제정 고시" 키워드에 걸리는 법령·고시만 대상이라, 안전보건과 직접 관련 없어 보이는 법령(예: 도로교통법의 "과속")은 키워드 검색에 잡히지 않습니다. 이 기능을 켜면 매일 새벽 1시에 법령(법률/시행령/시행규칙)과 행정규칙(고시/예규/훈령) 전체(모든 부처)를 목록 조회 API로 끝까지 훑어 본문을 캐시합니다 - 아직 등록/키워드 매칭 안 된 것도 모두 포함됩니다. 공포번호가 바뀌지 않은 항목은 상세조회를 건너뛰어서, 처음 한 번(수만 건 대상이라 몇 시간 이상 걸릴 수 있음)만 오래 걸리고 그다음부터는 실제로 개정·신규 제정된 것만 다시 받아와 훨씬 빨라집니다. (같은 새벽 1시에 위 "신규 제정 고시 자동 탐지"도 함께 실행됩니다. 새벽 1시에 컴퓨터가 꺼져 있어 못 돌았다면, 프로그램을 다음에 켤 때 대신 한 번 자동으로 실행됩니다.)

안전보건 뉴스 게시판

대시보드 상단에 자동 스크롤로 표시되는 고용노동부·안전보건공단 안전보건 이슈, 중대재해 뉴스의 출처(RSS/Atom 피드 주소)를 설정합니다. 기본값은 구글 뉴스 검색 RSS(news.google.com/rss/search)로 채워져 있어 별도 설정 없이도 동작하지만, 고용노동부·안전보건공단의 공식 RSS 주소를 알고 있다면 그 주소로 바꿔도 됩니다(표준 RSS 2.0 또는 Atom 형식이면 어떤 주소든 동작합니다). 피드를 가져오지 못하는 동안(네트워크 차단 등)에는 게시판이 비어 보이지 않도록 예시 데이터로 채워지며, 대시보드에 "예시 데이터" 표시가 함께 뜹니다.

KOSHA 가이드 Open API (기술지원규정 조회서비스)

공공데이터포털에서 "한국산업안전보건공단_기술지원규정(코샤가이드) 조회서비스" API 활용신청이 승인되면 여기에 인증키를 입력하고 KOSHA 가이드 탭의 "API로 동기화"를 눌러 KOSHA GUIDE 전체 목록(지침번호· 명칭·공표일자·원문 다운로드 링크 포함)을 한 번에 받아올 수 있습니다. 검색 키워드를 따로 등록할 필요 없이 전체를 받아옵니다. 인증키는 공공데이터포털 활용신청 상세페이지의 "일반 인증키"를 그대로 붙여넣으면 됩니다(Encoding/Decoding 어느 쪽이든 상관없습니다). 요청 URL 주의: 그 페이지의 "서비스 URL" 칸에는 .../B552468/koshaguide까지만 나오고 뒤에 붙는 오퍼레이션 경로 (/getKoshaGuide)가 빠져 있으니, 아래 기본값처럼 /getKoshaGuide까지 붙은 형태여야 동작합니다.
